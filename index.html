Learning design

Short loops, real feedback, visible mastery.

This refresh borrows the best parts of interactive STEM courses: visual intuition before terminology, practice before polish, and mastery checks before moving on.

1

See the idea

Start with a concrete mental model: request, response, contract, failure, or pipeline.

2

Do one action

Run a command, edit a TODO, trigger a sandbox, or inspect a network trace.

3

Debug the edge

Break a key, force a timeout, trigger CORS, or compare two response shapes.

4

Prove mastery

Answer the checkpoint, run the verifier, then mark the phase complete.

Course Contract

What you'll be able to do, what you need first, and what's deliberately left out.

By the end you can

  • Call any HTTP API from curl, Python, and the browser
  • Authenticate with API keys kept out of git
  • Aggregate multiple sources with graceful failure
  • Deploy your own app to a public URL
  • Ship a scheduled, tested automation that notifies a channel

Before you start

  • Comfort in a terminal (cd, run commands)
  • Basic Python — functions, dicts, imports
  • A GitHub account
  • No prior API experience needed

Scope

  • In REST/HTTP, keys, JSON, CORS, deploy, cron, webhooks, CI
  • Out OAuth 2.0 flows, GraphQL, async frameworks, production-grade auth
  • Out-of-scope topics are pointed to in each phase's Go deeper links
Format: self-paced Level 1: 10 phases · ~10–12 hrs Level 2: 7 phases · ~12–16 hrs Assessment: per-phase checkpoints + a deployed capstone
